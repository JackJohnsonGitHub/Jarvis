# jarvis-branding.ts

**Link:** Local Extension

## Description
A project-specific branding extension that establishes the identity of the agent as "Jarvis". It configures custom greetings, personality traits, and visual identifiers to ensure a consistent persona throughout the session.

## Commands
- None.

## Usage Examples
- **Identity Application**: Automatically applied on agent startup to replace generic "Pi" references with "Jarvis".
