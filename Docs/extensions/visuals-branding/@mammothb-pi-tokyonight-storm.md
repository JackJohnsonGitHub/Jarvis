# @mammothb/pi-tokyonight-storm

**Link:** [https://pi.dev/packages/@mammothb/pi-tokyonight-storm](https://pi.dev/packages/@mammothb/pi-tokyonight-storm)

## Description
A custom TUI theme extension that applies the "Tokyo Night Storm" color palette to the Pi agent's interface. It focuses on high contrast and eye-comfort for long coding sessions.

## Commands
- None (Applied as a theme).

## Usage Examples
- **Visual Customization**: Once installed, the TUI's backgrounds, foregrounds, and accent colors are automatically updated to the Tokyo Night Storm palette.
