# @boofpackdev/pi-morph

**Link:** [https://pi.dev/packages/@boofpackdev/pi-morph](https://pi.dev/packages/@boofpackdev/pi-morph)

## Description
A utility for transforming or adapting agent outputs and prompts. It allows the user to "morph" the current content into a different format or style without rewriting the entire prompt.

## Commands
- `/morph`: Request a transformation of the current editor content.
- `/morph:plan`: Plan a content transformation.
- `/morph:work`: Execute the morphing work.
- `/morph:review`: Review the morphed content.
- `/morph:ship`: Finalize and "ship" the result.
- `/morph:run`: Run the transformation.
- `/morph:config`: Configure morphing parameters.
- `/morph:status`: Check the status of a morphing operation.
- `/morph:recover`: Recover a previous state.
- `/morph:reset`: Reset the morphing state.
- `/morph:team`: Manage the morphing team/agent settings.
- `/morph:web`: Use web-based transformation tools.

## Usage Examples
- **Format Conversion**: `/morph "convert this list of requirements into a professional Markdown table"`
