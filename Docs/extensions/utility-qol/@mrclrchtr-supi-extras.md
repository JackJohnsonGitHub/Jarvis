# @mrclrchtr/supi-extras

**Link:** [https://pi.dev/packages/@mrclrchtr/supi-extras](https://pi.dev/packages/@mrclrchtr/supi-extras)

## Description
A suite of Quality of Life (QoL) enhancements for the Pi TUI. It includes tools for managing prompt drafts, visual feedback, and editing shortcuts to make the agent interaction more fluid.

## Commands
- `/supi-stash`: Opens the stash picker overlay to browse, restore, or delete saved prompt drafts.
- `/supi-settings`: Access Supi extension settings.
- `/exit`: Shortcut for exiting/closing (provided by aliases).
- `/clear`: Shortcut for clearing the console (provided by aliases).
- `/e`: Shortcut for editor-related actions (provided by aliases).

## Shortcuts
- `Alt+T`: Stash the current editor text as a draft.

## Usage Examples
- **Saving a Draft**: Type a long, complex prompt, press `Alt+T`, give it a name (e.g., "Refactor Plan"), and the text is saved and cleared from the editor.
- **Restoring a Draft**: Type `/supi-stash`, select "Refactor Plan" from the list, and press Enter to restore it to the editor.
