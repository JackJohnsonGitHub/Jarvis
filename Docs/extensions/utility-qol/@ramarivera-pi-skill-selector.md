# @ramarivera/pi-skill-selector

**Link:** [https://pi.dev/packages/@ramarivera/pi-skill-selector](https://pi.dev/packages/@ramarivera/pi-skill-selector)

## Description
A productivity tool that enables fuzzy-searching through available agent skills. Instead of remembering the exact name of a skill, users can quickly filter through them and insert the correct command into the prompt.

## Commands / Triggers
- `$` key: Opens the fuzzy-search skill selector.
- `/skill-selector`: Open the skill selector manually.

## Usage Examples
- **Quick Skill Insertion**: Type `$` in the editor, search for "visual", and select `visual-explainer` to automatically insert `/skill:visual-explainer` into your prompt.
