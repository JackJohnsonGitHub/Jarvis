# @2008muyu/pi-plan

**Link:** [https://pi.dev/packages/@2008muyu/pi-plan](https://pi.dev/packages/@2008muyu/pi-plan)

## Description
Provides structured planning capabilities for the agent. It allows the agent to decompose complex goals into a series of actionable steps, creating a roadmap that can be verified and adjusted before actual implementation begins.

## Commands
- `/plan`: Initiate the planning process for a specific goal.
- `/plan-list`: List active plans.
- `/plan-clean`: Clean up plan state.
- `/plan-abandon`: Abandon the current plan.
- `/plan-resume`: Resume a previous plan.
- `/plan-exit`: Exit the planning mode.
- `/plan-help`: Get help for planning commands.
- `/todos`: List and manage task todos.
- `/plan-settings`: Configure planning behavior.

## Usage Examples
- **Task Decomposition**: `/plan "Refactor the database schema to support multi-tenancy"`
