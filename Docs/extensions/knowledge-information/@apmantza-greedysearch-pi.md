# @apmantza/greedysearch-pi

**Link:** [https://pi.dev/packages/@apmantza/greedysearch-pi](https://pi.dev/packages/@apmantza/greedysearch-pi)

## Description
A high-fidelity research tool that uses a multi-engine AI search approach. It plans follow-up actions, fetches multiple sources, and audits citations to produce a structured research bundle, ensuring high accuracy and evidence-backed answers.

## Commands
- `/greedy-search`: Execute a comprehensive research query.
- `/greedy-visible`: Toggle visibility of the greedy search process.
- `/greedy-status`: Check the status of current research tasks.
- `/greedy-kill`: Terminate active research processes.
- `/set-greedy-locale`: Set the search locale/region.

## Usage Examples
- **Deep Technical Research**: `/greedy-search "Compare the memory overhead of Bun vs Node.js 22 for high-concurrency WebSocket servers"`
