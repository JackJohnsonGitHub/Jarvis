# pi-web-access

**Link:** [https://pi.dev/packages/pi-web-access](https://pi.dev/packages/pi-web-access)

## Description
Integrates real-time web search capabilities into the agent. It allows the agent to browse the internet to fetch the latest documentation, news, or library updates, overcoming the knowledge cutoff of the underlying LLM.

## Commands
- `/web-search`: Perform a search query and retrieve results.

## Usage Examples
- **Checking Latest Docs**: `/web-search "React 19 official release notes"`
- **Researching a Library**: `/web-search "best practices for using zod with tRPC in 2026"`
