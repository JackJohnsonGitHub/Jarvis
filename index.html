Model Intelligence — Routing Tiers
Router Profile · auto
Quality-First Routing
A classifier (claude-haiku-4-5) reads each turn's intent and routes it to the appropriate model tier — defaulting to the strongest model available and routing down only for clearly mechanical work.
defaultProvider: router defaultModel: auto thinking: xhigh
Model Tiers
Three-Level Dispatch
Every request is classified into high / medium / low complexity before a model is chosen. High-tier work always goes to Fable-5 or Opus first; mechanical tasks route to the efficient tier.
profiles: auto, bulk, coding, ops, research, writing

Autonomy Policy — trusted after approval
✋
First Occurrence: Always Confirm
Send email, create/update calendar events, share or delete Drive files, and mutate homelab hosts always require explicit user confirmation on first use.
✓
Recurring Tasks: Auto-Execute
Once the user approves a specific recurring task (e.g. a standing inbox-triage routine), Jarvis may repeat that same task without re-asking.
🔄
New Categories: Fresh Approval
New categories of side effects, or material changes to an approved routine, always require fresh user approval — even if a similar action was previously approved.
